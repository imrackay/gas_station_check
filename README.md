# ระบบตรวจสอบน้ำมันคงเหลือปั๊มน้ำมัน - จังหวัดตรัง

Dashboard สำหรับตรวจสอบสถานะน้ำมันคงเหลือของปั๊มน้ำมันแบบ real-time เพื่อลดความตื่นตระหนกและกระจายการเติมน้ำมันให้สมดุล

## 🎯 วัตถุประสงค์

ในช่วงวิกฤตราคาน้ำมัน ประชาชนแห่เติมน้ำมันจนหมดปั๊มเพราะความตื่นตระหนก ระบบนี้จึงถูกสร้างขึ้นเพื่อ:
- แสดงสถานะน้ำมันคงเหลือของปั๊มแบบ real-time
- ลดความรู้สึก "ต้องรีบเติมก่อนจะหมด"
- กระจายการเติมน้ำมันให้สมดุล
- เพิ่มความโปร่งใสและความน่าเชื่อถือของข้อมูล

## 📊 ข้อมูลปั๊มปัจจุบัน

ครอบคลุมปั๊มน้ำมันในจังหวัดตรัง **68 ปั๊ม** (ข้อมูลจาก OpenStreetMap)
รวมพื้นที่ขอบจังหวัดที่ติดกับ พัทลุง, สตูล, กระบี่, นครศรีธรรมราช

แบ่งตามแบรนด์:
- PTT: 10 ปั๊ม
- Bangchak: 7 ปั๊ม
- PT: 4 ปั๊ม
- Caltex: 3 ปั๊ม
- Shell: 2 ปั๊ม
- Esso: 2 ปั๊ม
- ปั๊มอิสระ: 40 ปั๊ม

## ✨ คุณสมบัติ

- 🗺️ แสดงตำแหน่งปั๊มน้ำมันบนแผนที่แบบ interactive
- 📊 แสดงสถิติน้ำมันคงเหลือแบบ real-time
- 🎨 สีแสดงสถานะ: เขียว (มาก), ส้ม (ปานกลาง), แดง (น้อย), เทา (หมด)
- 🔄 อัพเดทข้อมูลอัตโนมัติทุก 30 วินาที
- 📍 ตรวจสอบตำแหน่ง GPS - อัพเดทได้เฉพาะคนที่อยู่ใกล้ปั๊ม (ภายใน 100 เมตร)
- ➕ เพิ่มปั๊มใหม่ได้ด้วยพิกัด GPS จริง
- 📱 รองรับการใช้งานบนมือถือ

## 🚀 การติดตั้งและใช้งาน

### ติดตั้ง Dependencies

```bash
npm install
```

### รันในโหมด Development

```bash
npm run dev
```

เปิดเบราว์เซอร์ที่: http://localhost:5173

### รันแยกส่วน

```bash
# Terminal 1 - Backend
npm run server

# Terminal 2 - Frontend
npm run client
```

### Build สำหรับ Production

```bash
npm run build
npm run preview
```

## 🌐 Deploy ขึ้น Internet

ดูคู่มือการ deploy ที่ [DEPLOYMENT.md](DEPLOYMENT.md)

### Deploy ด้วย Vercel (แนะนำ - ฟรี)

```bash
# ติดตั้ง Vercel CLI
npm install -g vercel

# Deploy
vercel

# Deploy production
vercel --prod
```

## 📡 API Endpoints

- `GET /api/stations` - ดึงข้อมูลปั๊มทั้งหมด
- `GET /api/stations/:id` - ดึงข้อมูลปั๊มเฉพาะ
- `POST /api/stations` - เพิ่มปั๊มใหม่
- `PUT /api/stations/:id` - อัพเดทข้อมูลน้ำมันคงเหลือ

## 🔧 การดึงข้อมูลปั๊มจาก OpenStreetMap

```bash
npm run fetch-stations
```

สคริปต์นี้จะดึงข้อมูลปั๊มน้ำมันจริงๆ จาก OpenStreetMap พร้อมพิกัดที่แม่นยำ

## 🛡️ ความปลอดภัยและความน่าเชื่อถือ

- ✅ ตรวจสอบตำแหน่ง GPS ก่อนอนุญาตให้อัพเดทข้อมูล
- ✅ ต้องอยู่ภายใน 100 เมตรจากปั๊มจริงๆ
- ✅ ข้อมูลพิกัดจาก OpenStreetMap (แม่นยำ 100%)
- ✅ แสดงเวลาอัพเดทล่าสุด

## 📱 การใช้งาน

### สำหรับประชาชน
1. เปิดเว็บไซต์
2. ดูแผนที่และสถานะปั๊มต่างๆ
3. คลิกที่ปั๊มเพื่อดูรายละเอียด
4. เลือกปั๊มที่มีน้ำมันเหลือมากไปเติม

### สำหรับเจ้าหน้าที่ปั๊ม
1. คลิกที่ปั๊มของตนเองบนแผนที่
2. คลิกปุ่ม "อัพเดทข้อมูล"
3. ระบบจะตรวจสอบว่าคุณอยู่ใกล้ปั๊มจริงๆ
4. กรอกจำนวนน้ำมันคงเหลือ
5. บันทึก

### เพิ่มปั๊มใหม่
1. ไปที่ `/add-station.html`
2. คลิกบนแผนที่หรือใช้ตำแหน่งปัจจุบัน
3. กรอกข้อมูลปั๊ม
4. บันทึก
